プライバシーポリシー

おかーるこーゆ 投稿ツール(以下「本ツール」)における、Google ユーザーデータの取り扱いについて定めます。

1. YouTube API サービスの利用

本ツールは YouTube API サービス(YouTube Data API v3・YouTube Analytics API)を利用しています。本ツールを利用することで、YouTube 利用規約に同意したものとみなされます。Google によるデータの取り扱いは Google プライバシーポリシーをご確認ください。

2. 利用者

本ツールは運営者本人が、自分の管理する YouTube チャンネル「おかーるこーゆ」にだけ使う個人用ツールです。運営者以外の方のアカウントでの利用は想定しておらず、そのデータにはアクセスしません。

3. 取得する情報

(1) Google アカウント・認証に関する情報

  • OAuth のアクセストークン・更新トークン、許可された権限の範囲、有効期限
  • 認証したチャンネルの ID と名前(正しいチャンネルかを確認するため)

メールアドレス、氏名、プロフィール写真など、Google アカウントの個人情報を得る権限は求めておらず、取得しません。

(2) 自分のチャンネルの YouTube データ

  • アップロードした動画の ID、タイトル、説明文、公開状態、公開予約日時、公開日時、長さ
  • 動画ごとの再生回数、高評価数、コメント数(件数のみ。コメント本文や投稿者の情報は本ツールでは取得しません)
  • YouTube アナリティクスの集計データ(視聴回数、総再生時間、平均視聴時間、視聴維持率、トラフィック ソース、視聴者の年齢層・性別の割合など)。個々の視聴者を特定できる情報は含まれません

(3) 公開されている他の動画・チャンネルの情報(市場調査)

  • 検索で見つけた公開動画のタイトル、説明文、タグ、公開日時、長さ、再生回数・高評価数・コメント数(件数)、サムネイル画像、チャンネル名と登録者数

これらは題材や構成の傾向をつかむためだけに使い、取得から30日以内に削除します(下記7)。数値を加工した独自の指標を作って保存・公開することはしません。

4. 利用目的

  • 自分のチャンネルへの動画の非公開アップロード、サムネイルの設定、公開予約の設定
  • 投稿の二重送信の防止、正しいチャンネルへの投稿であることの確認
  • 自分の動画の成績の分析と、今後の動画の企画・構成の改善

取得したデータを広告に使うこと、販売すること、上記以外の目的に使うことはありません。

5. 保存場所と保護

  • データは運営者の PC(Windows)にだけ保存します。本ツール専用のサーバーやクラウドへの保存は行いません。
  • OAuth のトークンは Windows のデータ保護機能(DPAPI)で暗号化し、運営者の Windows ユーザーだけが復号できる形で保存します。トークンを画面・ログ・ソースコード管理(Git)に出力しないよう、自動検査を行っています。

6. 第三者への提供・外部サービスでの処理

  • 取得したデータを第三者に提供・販売することはありません(法令に基づく場合を除く)。
  • 動画の分析と改善の作業に、AI アシスタント(Anthropic の Claude Code、OpenAI の Codex)を使います。それぞれ次のデータがそのサービスで処理されることがあります。OAuth のトークン、クライアントシークレット、パスワードはどちらにも渡しません。
    • Claude Code: 上記3(2)の自分の動画の情報・統計・アナリティクスの集計と、3(3)の市場調査の情報、およびそれらの分析結果
    • Codex: 自分が制作した動画のレビュー用素材(動画から抜き出した静止画、台本)。YouTube API から取得したデータは依頼に含めません

7. 保存期間

情報保存期間
OAuth のトークン本ツールの利用を続ける間。連携の解除または利用終了のときに削除します。
自分のチャンネルの動画情報・統計・アナリティクスの集計本ツールの利用を続け、認可が有効な間。認可が有効であることと動画が存在することを定期的に(少なくとも30日ごとに)確認し、YouTube 上から削除された動画の記録は取り除きます。30日を超えて認可を確認できない場合は、そのチャンネルの保存データを削除します。
他の動画・チャンネルの公開情報(市場調査)とその集計取得から30日以内に削除するか、最新の情報に更新します。
運営者が作成した考察・改善メモ運営者自身の文章として保存します。他の動画・チャンネルの再生回数などの数値は、取得から30日を過ぎたものを残しません。

8. アクセスの取り消しとデータの削除

  • 本ツールには、アクセス許可を取り消す機能があります(運営者が PC で実行するコマンド)。この機能で取り消すと、Google 側でトークンを直ちに無効にし、保存していたトークンと、YouTube から取得して保存したデータを直ちに(遅くとも7日以内に)削除します。
  • 本ツールへのアクセス許可は、Google アカウントのセキュリティ設定(サードパーティ アプリとサービス)からもいつでも取り消せます。この場合、本ツールは定期的な確認でトークンを更新できなくなったことを検知し、関連データを30日以内に削除します。
  • 保存データの削除を希望する場合は、下記の連絡先にご連絡ください。7日以内に削除します。本ツールが保存している写しを削除しても、YouTube 上の動画やデータには影響しません。

9. Cookie など

本ツールはブラウザの Cookie などを使って利用者の端末に情報を保存しません(認証の際に Google のログイン画面を開くことを除く)。このページは GitHub Pages で公開しており、アクセスの記録は GitHub 社のプライバシーステートメントに従って扱われます。

10. Google API サービスのユーザーデータ ポリシーの順守

本ツールによる Google API から受け取った情報の使用と他のアプリへの転送は、限定使用の要件を含め、Google API サービスのユーザーデータ ポリシーに従います。
