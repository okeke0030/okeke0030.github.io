おかーるこーゆ 投稿ツール

YouTube チャンネル「おかーるこーゆ」(アニメ・物語形式のショート動画)の運営者が、自分のチャンネルの投稿・公開予約・分析を自動化するために使う個人用ツールです。

このツールでできること

  • 運営者が制作し、品質確認を終えた動画を、YouTube チャンネル「おかーるこーゆ」へ非公開でアップロードする
  • アップロードした動画に、公開予約日時(1日1本)を設定する
  • 自分の動画の公開状態・予約日時・再生回数・高評価数・コメント数を確認する
  • YouTube アナリティクスの集計データ(視聴回数・視聴時間・視聴維持率など)を取得し、動画の改善に使う
  • 公開されている同じジャンルの動画を検索し、題材や構成の傾向を調べる(市場調査)

利用者

このツールは運営者本人が、自分の管理するチャンネルにだけ使います。一般の方への提供・ログイン画面の公開は行っていません。運営者以外のアカウントのデータにはアクセスしません。

Google のユーザーデータを求める理由

このツールは YouTube API サービス(YouTube Data API v3・YouTube Analytics API)を使います。Google の OAuth 2.0 で、次の権限を求めます。メールアドレスやプロフィールなど、Google アカウントの個人情報を得る権限は求めません。

権限(スコープ)使う目的
https://www.googleapis.com/auth/youtube.upload自分のチャンネルへ動画を「非公開」でアップロードし、サムネイルを設定するため
https://www.googleapis.com/auth/youtubeアップロード済みの自分の動画に公開予約日時を設定するため(公開予約以外の設定変更・削除は行いません)
https://www.googleapis.com/auth/youtube.readonly認証したチャンネルが本人のチャンネルであることの確認、自分の動画の公開状態・予約日時・再生回数などの確認、公開されている動画の検索(市場調査)のため
https://www.googleapis.com/auth/yt-analytics.readonly自分のチャンネルの視聴データ(集計値)を分析し、動画の改善に役立てるため

  • このツールを使うことで、YouTube 利用規約に同意したものとみなされます。
